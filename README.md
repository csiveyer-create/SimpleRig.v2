# SimpleRig 2D

This is a standalone browser app for GitHub Pages.

## Included

- 2D workspace with uploaded photo/plan backgrounds
- Drag-and-drop asset library
- Import PNG, SVG, JPG and WebP assets
- Move, scale, rotate, flip and four-corner perspective distortion
- Rig lines, measurement lines and labels
- Layers, undo/redo and PNG export
- Local project save, rename, duplicate, delete and JSON backup
- Drag-and-drop calendar
- Harness reference
- Manual mechanical advantage/disadvantage calculator
- Optional live Google image search

## GitHub Pages

Upload the contents of this folder to the repository root. Then open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**.

## Google image search

The app uses Google Programmable Search rather than scraping Google Images. Enter your own API key and Programmable Search Engine ID (CX) in the app. Restrict the API key to your GitHub Pages domain.

Remote sites may block canvas access. When a result will not display or prevents PNG export, download an authorised copy from its source page and import it locally.

## Safety

The load calculator is for planning only and does not replace manufacturer guidance, a competent-person assessment, engineering review or an approved rigging procedure.
